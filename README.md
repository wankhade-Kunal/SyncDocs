# SyncDocs Pro 🚀

Real-time collaborative document editor (Google Docs–style) built with MERN + Socket.io.

👉 Supports live editing, version history, sharing, and multi-user collaboration.

## ✨ Key Features

* 📝 Real-time collaborative editing (Socket.io)
* ⚡ Conflict resolution using Operational Transformation (OT)
* 👥 Multi-user presence & live cursor tracking
* 🔗 Document sharing with role-based access (Editor / Viewer)
* 📋 Version history with restore functionality
* ⭐ Star & Trash system (document management)
* 🎨 Clean, responsive dashboard UI (Google Docs inspired)

---

## 🛠 Tech Stack

**Frontend:** React 18, Vite, React Router, Quill.js, Axios, Socket.io-client
**Backend:** Node.js, Express, Socket.io
**Database:** MongoDB
**Auth:** JWT + bcryptjs

---

## 💡 Why This Project?

This project demonstrates:

* Real-time systems using WebSockets

## ⚙️ Quick Setup

```bash
# Clone repo
git clone https://github.com/wankhade-Kunal/syncdocs.git

# Install dependencies
cd syncdocs
cd server && npm install
cd ../client && npm install

# Run backend
cd ../server
npm run dev

# Run frontend
cd ../client
npm run dev
```
